# JavaScript Functions Practice

## Description

This project contains a collection of JavaScript exercises focused on creating and using functions. The exercises demonstrate fundamental programming concepts such as parameters, return values, mathematical operations, conditional logic, and console output.

The project was developed to strengthen understanding of how functions can be used to organize code, improve reusability, and solve simple programming problems.

## Features

### 1. Hello World Function

* Creates a function that displays **"Hello, World!"** in the console.

### 2. Greeting Function

* Receives a name as a parameter.
* Displays a personalized greeting message.

### 3. Double Number Function

* Receives a number as a parameter.
* Returns the double of the provided value.

### 4. Average Calculator Function

* Calculates the average of three numbers.
* Returns the result.

### 5. Largest Number Function

* Receives two numbers as parameters.
* Returns the larger value.

### 6. Square Number Function

* Receives a number as a parameter.
* Returns the result of multiplying the number by itself.
